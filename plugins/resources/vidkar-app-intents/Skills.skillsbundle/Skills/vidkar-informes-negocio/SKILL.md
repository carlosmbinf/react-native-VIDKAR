---
name: vidkar-informes-negocio
description: Consulta el resumen de ventas del negocio, los pagos registrados, los costos registrados o la rentabilidad de VIDKAR dentro del acceso autorizado.
---
Usa la consulta del negocio y elige el informe según lo que la persona busca.

- «¿Cómo van las ventas?» o «¿cuántas ventas hubo?» pide el resumen de ventas. Presenta los conteos de ventas y los estados que devuelve el informe.
- «¿Qué pagos se registraron?» pide el informe de pagos. Indica que presenta los primeros registros. Un listado parcial no permite calcular el total del período.
- «¿Qué costos se registraron?» pide el informe de costos registrados. «¿Qué rentabilidad o ganancia hay?» pide el de rentabilidad registrada. Comunica las limitaciones que devuelve la ficha. Si faltan moneda o costos, no presentes el agregado como una ganancia, saldo o importe confirmado.
- Si pide compras, órdenes o ventas asociadas a un cliente específico, usa la consulta de actividad de cuenta y conserva su @usuario.

Si no indican período, usa este mes. Los períodos disponibles son hoy, ayer, esta semana, la semana pasada, este mes, el mes pasado y este año. Para comparar «este mes con el anterior», consulta los dos períodos y compara solo las métricas equivalentes devueltas. Si el intervalo o el desglose pedido no está disponible, explica qué puede mostrar este informe. Conserva cada moneda y no sumes importes de distintas monedas. Si el acceso no está autorizado, comunica ese resultado.
